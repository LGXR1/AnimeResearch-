# AnimeResearch 改进计划

> 2026-08-12 · v0.0.5
>
> 核心理念：**打开即搜，搜完即走**。不加登录、不加收藏、不加任何阻碍用户离开的功能。

---

## 已知欠账

| 问题 | 优先级 |
|------|--------|
| 移动端体验差（反馈栏不可见、搜索框太小、结果两列挤） | 🔴 高 |
| 无 Open Graph 标签，分享链接只有光秃秃的 URL | 🟠 中 |
| 无 404 页面，访问错误路由白屏 | 🟠 中 |
| Supabase 密钥硬编码在两处源码中 | 🟠 中 |
| 无错误边界，组件报错整页白屏 | 🟠 中 |
| 三个页面复制粘贴同一段背景样式 | 🟡 低 |
| 搜索无防抖，每次按键都发请求 | 🟡 低 |
| 无 favicon，浏览器标签页一片空白 | 🟡 低 |
| 声优名称为纯文本，不可点击搜索 | 🟡 低 |

- 做一个樱花或"尋"字小图标
- 放 `public/favicon.ico`

- `src/pages/NotFoundPage.jsx`
- 日系风格提示 + 返回首页链接

### 1.3 提取 Layout 组件
- `src/components/Layout.jsx`
- 统一深色渐变背景和装饰元素
- 三个页面共享

### 1.4 环境变量
- Supabase URL 和 key 改为 `import.meta.env.VITE_*`

## 二、体验提升

### 2.1 移动端适配
- 反馈栏：移动端改为右下角浮动按钮 → 弹出抽屉
- 搜索结果：手机端合理列数
- 标题和搜索框字号适配
- 详情页图文排版适配

### 2.2 分享预览（OG 标签）
- 角色详情页 `<meta og:title>` + `og:image` + `og:description`
- 分享到 QQ/微信/Discord 有卡片预览

### 2.3 搜索防抖
- SearchBar 加 300ms 防抖
- 搜索中显示加载状态
- 无结果时展示推荐标签

### 2.4 错误边界
- `ErrorBoundary.jsx` 包裹整个应用
- 报错时优雅降级，不白屏

## 不做的

以下是有意不做的事情：

- ❌ 收藏 / 书签 — 注册登录太重，localStorage 收藏对随搜随走没意义
- ❌ PWA / 离线缓存 — 搜动漫角色不需要离线
- ❌ 每日推荐 — 用户是来找人的，不是来逛的
- ❌ SSR — SPA 够用，搜索引擎不需要收录角色页
- ❌ 骨架屏 — 比 spinner 复杂但收益有限，一个简单网站不需要
- ❌ 语义搜索 — 关键词匹配够用，引入 Embeddings 成本太高
- ❌ 数据流水线 — 手工添加角色目前可控
